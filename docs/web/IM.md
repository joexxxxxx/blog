# IM（Electron）

## WebSocket

### Web Worker 心跳机制

使用 Web Worker 处理心跳定时器，解决 Electron 窗口不聚焦或隐藏时定时器不准确的问题，确保 WebSocket 心跳包稳定发送。

### 指数退避重连算法

- 初始重连间隔：10 秒
- **窗口聚焦**：5~10 秒区间内随机重连
- **窗口失焦**：10~15 秒区间内随机重连

## SQLite

## SQLite数据库操作使用TYPEORM

### 路由式数据访问

在主线程通过路由形式注册数据请求方法，保持与常规接口请求一致的调用方式。

### 并发控制

使用 RxJS 队列限制 SQLite 操作并发，保障数据库可用性。

### 数据一致性保障

在接口请求层使用 RxJS 适配器：
- 检查 SQLite 数据连续性与准确性
- 极端情况下（数据库不可用）自动降级为服务端接口同步
- RAGMA busy_timeout=5000 数据库超时，自动降级为服务端接口同步

### 大量数据写入

在处理大量数据写入时，采用分批处理和异步写入策略，避免阻塞主线程，确保界面流畅。
- 进行数据切片，每次处理固定数量的数据项
- 使用异步API进行数据库写入，避免阻塞主线程

## 页面响应优先

在用户登录的过程中，优先保证页面的响应速度和用户体验。
 - 在登录成功后需要通过接口获取最新的回话列表和最新的消息，这个时候优先取本地数据库的数据，然后接口请求完毕后再进行更新
