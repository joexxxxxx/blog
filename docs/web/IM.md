# IM（Electron）

## WebSocket

### Web Worker 心跳机制

使用 Web Worker 处理心跳定时器，解决 Electron 窗口不聚焦或隐藏时定时器不准确的问题，确保 WebSocket 心跳包稳定发送。

### 指数退避重连算法

- 初始重连间隔：10 秒
- **窗口聚焦**：5~10 秒区间内随机重连
- **窗口失焦**：10~15 秒区间内随机重连

## SQLite

### 路由式数据访问

在主线程通过路由形式注册数据请求方法，保持与常规接口请求一致的调用方式。

### 并发控制

使用 RxJS 队列限制 SQLite 操作并发，保障数据库可用性。

### 数据一致性保障

在接口请求层使用 RxJS 适配器：
- 检查 SQLite 数据连续性与准确性
- 极端情况下（数据库不可用）自动降级为服务端接口同步
